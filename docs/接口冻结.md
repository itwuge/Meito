# 接口冻结（M1）

- 契约版本：`0.1.0`
- 冻结日期：`2026-11-08`
- 状态：`frozen`
- 唯一机器可读来源：`contracts/`；本文只做人类索引，不重复定义细节。
- 冻结后只允许**追加**：新增命令/字段/错误码/状态；重命名或删除必须升 `contractVersion` 并写变更记录。

## 1. 契约文件

| 文件 | 覆盖 |
|---|---|
| `contracts/contract-version.json` | 版本、冻结状态、文件清单、BYO TURN 预留状态 |
| `contracts/cli.json` | 子命令、参数、环境变量、退出码语义 |
| `contracts/error-codes.json` | 错误码表、错误码→退出码映射 |
| `contracts/log.json` | JSONL 字段、级别、阶段枚举、脱敏规则、环境台账字段 |
| `contracts/workflow.json` | workflow 输入/输出、Job Summary、artifact manifest 入口、BYO TURN |
| `contracts/state-machine.json` | 状态/事件/转移、超时、自动取消 |
| `contracts/artifact-manifest.schema.json` | artifact manifest 的 JSON Schema |

校验命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\contract-check.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\arch-check.ps1
```

`contract-check.ps1` 已接入 `arch-check.ps1`；后者失败即阻断合并。

## 2. CLI 契约

- 二进制：`meito`。
- 子命令：`init`、`doctor`、`up`、`web`、`share`、`status`、`connect`、`entry`、`pull`、`kconfig`、`down`、`logs`、`env`、`clean`、`p2p`、`config`。
- 全局参数：`--repo`、`--config`、`--session`、`--log-level`、`--json`、`--version`、`--help`。
- 环境变量：`MEITO_REPO`、`MEITO_CONFIG`、`MEITO_LOG`、`MEITO_LINK_URL`、`MEITO_FRPS_TOKEN`、`MEITO_TAILSCALE_AUTHKEY`、`MEITO_BUILD_DIR`、`GH_TOKEN`；BYO TURN 三个变量为 `reserved`，默认不启用。
- 退出码：0 成功；1 内部错误；2 用法/配置；3 鉴权；4 预检/bootstrap；5 dispatch/排队；6 link/P2P/host key；7 入口；8 artifact/apply；9 超时；10 取消；11 网页无直连或检测到中继；12 日志不可用/孤儿。
- 错误码以 `contracts/error-codes.json` 为准；新增错误码必须同时给退出码映射。

## 3. 日志契约

- 唯一格式 JSONL；唯一路径 `logs/session-<id>.jsonl`；环境台账 `logs/env-session-<id>.json`。
- 固定字段六项：`ts`、`level`、`session_id`、`stage`、`event`、`error_code`；额外字段不得替代固定字段。
- 级别：`info`（默认）、`debug`、`trace`；开关 `--log-level` 或 `MEITO_LOG`；`trace` 需显式确认。
- `session_id` 为 UUID v4，贯穿本地/runner/协调服务。
- 阶段枚举与 `contracts/state-machine.json` 的 states 完全一致；不允许只在一侧新增阶段。
- 脱敏在日志层强制执行，替换为 `[REDACTED]`；禁止用 `print`/`println!` 当日志（CLI 展示层除外）。

## 4. Workflow 契约

- 触发：`workflow_dispatch`；模板 `templates/meito-session.yml`；权限 `contents: read`、`actions: read`；`timeout-minutes: 360`。
- 输入共 10 个：`session_id`、`ref`、`max_minutes`、`idle_minutes`、`p2p_provider`、`entry`、`channel`、`artifact_spec`、`flags`、`meito_version`。
- 约束：`max_minutes ≤ 300`；`p2p_provider` 仅 `frp_xtcp`/`tailscale_direct`；`entry` 仅 `terminal`/`graphical`/`both`；输入不含秘密。
- 输出：
  - 连接串/连接包：仅经 `meito-link` 加密下发；不进 artifact、不进日志、不进 Job Summary。
  - 读链接：一次性只读 token；写链接：一次性写 token；Job Summary 只写“存在/过期时间”，不写完整链接。
  - Job Summary 字段：`session_id`、`status`、`entry`、`read_link_present`、`write_link_present`、`expires_at`、`artifact_name`。
  - artifact manifest：`artifact-manifest.json`，校验方式为 manifest 内 SHA256 + `filesSha256` + `archiveSha256` + `guardPassed`。
- artifact 上传前执行 `artifact_guard`：路径白名单 + 正则扫描；命中即阻断。

## 5. 状态机契约

- 初始状态：`idle`；终态：`done`、`cancelled`、`failed_*`、`no_direct_path`、`orphaned`。
- 主路径：`idle → preflight → dispatching → queued → runner_starting → p2p_connecting → link_ready → waiting_for_join → entry_starting → connected → ending → collecting → done`。
- 关键分支：
  - 预检失败 → `failed_preflight`；dispatch 失败 → `failed_dispatch`；排队超时 → `failed_queue_timeout`。
  - runner/bootstrap 失败 → `failed_bootstrap`；P2P 失败 → `failed_p2p`；网页无直连 → `no_direct_path`。
  - 入口失败 → `failed_entry`；收集失败 → `failed_collect`；裸停止 → `cancelled`。
- 超时与自动取消：
  - job 硬上限 360 min；会话默认 60 min、最大 300 min；空闲 10 min。
  - 无人加入 5 min → `join_timeout` → `cancelled`（`E_NO_JOIN_TIMEOUT`）。
  - 重连上限：SSH 3 次、ICE 2 次；超过 → `failed_p2p`。
  - 距最大时长 10 min 先 checkpoint。

## 6. BYO TURN（待拍板）

- 状态：`reserved`；默认关闭（`enabled=false`）；`decision=pending`；决策编号 `D-4`。
- 接口位：`contracts/cli.json` 的 `MEITO_TURN_*`、`contracts/workflow.json` 的 `byoTurn`、错误码 `E_WEB_RELAY_USED`。
- 默认分支 A：不允许 BYO TURN，TURN URL 永远为空；分支 B：用户自带中继，仍需显式开启并标注“使用中继”。
- 在用户拍板前，任何实现不得把 BYO TURN 设为默认，也不得让 Meito 服务器托管 TURN。

## 7. 冻结后的并行规则

1. 两个外壳（`meito-cli`、`meito-web`）只能依赖 `meito-core` 的公共接口；禁止各自定义状态机/artifact/P2P 策略。
2. 新增命令/参数/字段/状态/错误码：先改 `contracts/`，再改代码，再更新本文，最后跑 `contract-check`。
3. 重命名/删除：必须升 `contractVersion`、写 `docs/变更记录.md`、评估两外壳影响。
4. M1 验收：`cargo check` 通过；两外壳 stub 编译通过；`contract-check` 与 `arch-check` 退出 0；SC-18 记录证据。
