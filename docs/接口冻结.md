# 接口冻结（M1/M3）

- 契约版本：`0.3.5`
- 冻结日期：`2026-11-08`
- 状态：`frozen`
- 唯一机器可读来源：`contracts/`；本文只做人类索引，不重复定义细节。
- 冻结后只允许**追加**：新增命令/字段/错误码/状态；重命名或删除必须升 `contractVersion` 并写变更记录。

## 2. CLI 契约

- 二进制：`meito`。
- 子命令：`init`、`doctor`、`up`、`web`、`share`、`status`、`connect`、`entry`、`pull`、`kconfig`、`down`、`logs`、`env`、`clean`、`p2p`、`config`。
- 全局参数：`--repo`、`--config`、`--session`、`--log-level`、`--json`、`--version`、`--help`。
- 环境变量：`MEITO_REPO`、`MEITO_CONFIG`、`MEITO_LOG`、`MEITO_LINK_URL`、`MEITO_FRPS_TOKEN`、`MEITO_TAILSCALE_AUTHKEY`、`MEITO_BUILD_DIR`、`GH_TOKEN`；BYO TURN 三个变量为 `reserved`，默认不启用。
- 退出码：0 成功；1 内部错误；2 用法/配置；3 鉴权；4 预检/bootstrap；5 dispatch/排队；6 link/P2P/host key；7 入口；8 artifact/apply；9 超时；10 取消；11 网页无直连或检测到中继；12 日志不可用/孤儿。
- 错误码以 `contracts/error-codes.json` 为准；新增错误码必须同时给退出码映射。

## 3. 日志契约

- 唯一格式 JSONL；唯一路径 `logs/session-<id>.jsonl`；环境台账 `logs/env-session-<id>.json`。
- 固定字段六项：`ts`、`level`、`session_id`、`stage`、`event`、`error_code`；额外字段不得替代固定字段。
- 级别：`info`（默认）、`debug`、`trace`；开关 `--log-level` 或 `MEITO_LOG`；`trace` 需显式确认。
- `session_id` 为 UUID v4，贯穿本地/runner/协调服务。
- 阶段枚举与 `contracts/state-machine.json` 的 states 完全一致；不允许只在一侧新增阶段。
- 脱敏在日志层强制执行，替换为 `[REDACTED]`；禁止用 `print`/`println!` 当日志（CLI 展示层除外）。

## 4. Workflow 契约

- 触发：`workflow_dispatch`；模板 `templates/meito-session.yml`；权限 `contents: read`、`actions: read`；`timeout-minutes: 360`。
- 输入共 10 个：`session_id`、`ref`、`max_minutes`、`idle_minutes`、`p2p_provider`、`entry`、`channel`、`channel_write_token`、`channel_public_key`、`flags`。
- `channel` 为不透明 id（≤128），不得包含 token 或公钥；`channel_write_token` 与 `channel_public_key` 为独立输入。
- `flags` 为 JSON，承载 `artifact_spec`、`meito_version`、`allowed_actors` 及分享/只读/超时等开关；`artifact_spec` 与 `meito_version` 不再作为顶层输入。
- 约束：`max_minutes ≤ 300`；`p2p_provider` 仅 `frp_xtcp`/`tailscale_direct`；`entry` 仅 `terminal`/`graphical`/`both`；输入不含秘密。
- 输出：
  - 连接串/连接包：仅经 `meito-link` 加密下发；不进 artifact、不进日志、不进 Job Summary。
  - 读链接：每通道签发一次只读 token，可重复读取至 `DELETE`/TTL（≤10 次）；写链接：每通道签发一次写 token；Job Summary 只写“存在/过期时间”，不写完整链接。
  - Job Summary 字段：`session_id`、`status`、`entry`、`read_link_present`、`write_link_present`、`expires_at`、`artifact_name`。
  - artifact manifest：`artifact-manifest.json`，校验方式为 manifest 内 SHA256 + `filesSha256` + `archiveSha256` + `guardPassed`。
- artifact 上传前执行 `artifact_guard`：路径白名单 + 正则扫描；命中即阻断。

## 5. 状态机契约

- 初始状态：`idle`；终态：`done`、`cancelled`、`failed_*`、`no_direct_path`、`orphaned`。
- 主路径：`idle → preflight → dispatching → queued → runner_starting → p2p_connecting → link_ready → waiting_for_join → entry_starting → connected → ending → collecting → done`。
- 关键分支：
  - 预检失败 → `failed_preflight`；dispatch 失败 → `failed_dispatch`；排队超时 → `failed_queue_timeout`。
  - runner/bootstrap 失败 → `failed_bootstrap`；P2P 失败 → `failed_p2p`；网页无直连 → `no_direct_path`。
  - 入口失败 → `failed_entry`；收集失败 → `failed_collect`；裸停止 → `cancelled`。
- 超时与自动取消：
  - job 硬上限 360 min；会话默认 60 min、最大 300 min；空闲 10 min。
  - 无人加入 5 min → `join_timeout` → `cancelled`（`E_NO_JOIN_TIMEOUT`）。
  - 重连上限：SSH 3 次、ICE 2 次；超过 → `failed_p2p`。
  - 距最大时长 10 min 先 checkpoint。

## 5.1 新增契约要点（0.2.0）

- 连接包：magic `MEITO1`（6 字节）+ `formatVersion=1` + `algorithm_id=0`（`x25519-xchacha20poly1305`）+ 临时公钥 32 字节 + nonce 24 字节 + 含 tag 密文；整体 base64url 无填充。`meito-link` 只存密文、不解析、不写日志，单包上限 16384 字节。
- UDP 探测：报文 magic `MEITOUDP` + 8 字节随机 nonce，回执同 nonce；3 次尝试、每次 1 秒超时；目标来自 `meito.toml` 的 `[network] udp_probe_target`；`meito-link` UDP 监听默认关闭且不转发会话字节。
- 配置 fail-closed：`meito.toml` 缺失、缺 `security.allowed_actors` 或列表为空时全部拒绝；workflow 的 `flags.allowed_actors` 可覆盖，覆盖优先。
- 依赖锁定：`tools.lock.json` 的 `lockVersion` 只能为 `1`；条目 `status` 为 `pinned`/`unpinned`；`pinned` 必须有 `version`、`url`、64 位小写 SHA256；`unpinned` 拒绝安装并报 `E_UNPINNED_TOOL`；禁止 `curl | bash`。

## 5.2 新增契约要点（0.3.x）

- 通道 TTL `7200` 秒；单包上限引用 `contracts/connection-package.json` 的 `serverHandling.maxCiphertextBytes`（16384 字节），`link.json` 不复写数值。
- 注册必须同时提交 `channel_id`、`read_token_hash`、`write_token_hash`、`public_key`；令牌哈希为 `sha256`/`hex`，只用于校验、不落日志。
- 读/写 token 每通道各签发一次；读 token 不是只能读一次，`GET` 可重复至 `DELETE` 或 TTL，`maxReads=10`。
- 成功响应统一 `200`（注册/`PUT`/`GET`/`DELETE`）；同一通道仍存活时重复注册返回 `400`。
- 鉴权头统一 `Authorization: Bearer <token>`；读 token 只用于 `GET`，写 token 用于 `PUT` 与 `DELETE`。
- 限流：每通道每分钟 60、每 IP 每分钟 120、突发 10。
- 状态码：`success=200`、`duplicate_channel=400`、`bad_token=403`、`unknown_channel=404`、`too_large=413`、`rate_limited=429`、`method_not_allowed=405`、`malformed=400`、`internal=500`。
- 日志只允许 `channel_id`、大小、状态；禁止 blob 片段与任何摘要。

## 5.5 增量修订（0.3.3）

- 图形入口降级：`entry.json` 的 `requiredness` 把 `ports.graphical`、`ports.vnc`、`graphical.framebuffer`、`graphical.vncPasswordChars`、`graphical.vncPasswordDesOnly` 标为 `reserved`；`graphical.status=reserved`、`graphical.reason` 说明“渲染方案待定”。字段数值保留，不删除。
- 强制项不变：`ports.terminal`、`bind.address`、`bind.loopbackOnly`、`bind.allowWildcardBind` 与 ttyd 三个标志保持 `required`。
- v1 兜底：`v1GraphicalFallback.status=required`、`transport=ssh-x11-forwarding`、`sshFlag=-X`、`localXServer=true`；网页版候选 `webCandidates=[KasmVNC,noVNC,xpra]`、`webDecision=kasmvnc-preferred-novnc-fallback`。取舍结论与风险写入 design §10.8。
- `acceptance.json`：`graphical.status=reserved`、`graphical.optionalMetrics=[sc07VncPasswordOnlyMustFail]`；该指标 `optional`，不阻塞 v1 验收。
- 转正规则：任一图形字段由 `reserved` 改成 `required` 时，`docs/变更记录.md` 必须新增标题含「图形入口转正」的条目，否则 `contract-check` 失败。

## 5.7 增量修订（0.3.5）

- `connection-package.json` 新增 `kdf`：`HKDF-SHA256`，`ikm=x25519-shared-secret`，`salt=""`（`saltPolicy=empty-string-fixed`），`info=meito-v1/connection-package`（绑定协议版本与用途），`outputBytes=32`，`rawSharedSecretAsKey=false`。禁止直接把 X25519 共享密钥当 AEAD 密钥。
- 新增顶层 `aad`：`policy=none`、`aadBytes=0`；`algorithm.aad` 保持 `none`。启用或改变 AAD 必须提升 `formatVersion` 并新增 algorithm id。
- 新增 `ephemeralKey`（runner 每包生成）与 `keyLifecycle`：临时密钥每包生成、接收方密钥每作业生成、私钥不导出、共享密钥派生后清零、派生密钥用后清零；`zeroizeImplementation=zeroize`、`bestEffort=true`、`forensicResistance=false`，不声称可抵御内存取证。
- 新增 `testVectors`：生成脚本 `scripts/gen-connection-package-vector.py`，命令 `python scripts/gen-connection-package-vector.py`，依赖 `PyNaCl==1.6.2`；无系统随机源，连续两次输出逐字节一致。
- `contract-check` 新增 KDF/AAD/生命周期/向量脚本断言；实现约束记录于 design §5.11。

## 6. BYO TURN（待拍板）

- 状态：`reserved`；默认关闭（`enabled=false`）；`decision=pending`；决策编号 `D-4`。
- 接口位：`contracts/cli.json` 的 `MEITO_TURN_*`、`contracts/workflow.json` 的 `byoTurn`、错误码 `E_WEB_RELAY_USED`。
- 默认分支 A：不允许 BYO TURN，TURN URL 永远为空；分支 B：用户自带中继，仍需显式开启并标注“使用中继”。
- 在用户拍板前，任何实现不得把 BYO TURN 设为默认，也不得让 Meito 服务器托管 TURN。

## 7. 冻结后的并行规则

1. 两个外壳（`meito-cli`、`meito-web`）只能依赖 `meito-core` 的公共接口；禁止各自定义状态机/artifact/P2P 策略。
2. 新增命令/参数/字段/状态/错误码：先改 `contracts/`，再改代码，再更新本文，最后跑 `contract-check`。
3. 重命名/删除：必须升 `contractVersion`、写 `docs/变更记录.md`、评估两外壳影响。
4. M1 验收：`cargo check` 通过；两外壳 stub 编译通过；`contract-check` 与 `arch-check` 退出 0；SC-18 记录证据。
