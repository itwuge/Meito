# 开工清单（Meito 版）

本项目版本，只保留当前阶段需要勾选的动作；通用模板见经验库 `开工清单.md`。

## 每次开工

- [ ] 确认当前分支在 [分支归属.md](分支归属.md) 中，且归属线正确（R-T-11）。
- [ ] 确认本阶段判据已写在 `docs/验收记录/`（R-D-3）。
- [ ] 确认没有未提交的他人改动；不擅自 stash/rebase（R-T-7）。
- [ ] 确认本轮不引入中继、不引入 TURN、不新增 SPA 框架（硬约束）。
- [ ] 确认交互 job 不接触生产凭据（安全隔离）。

## 每次收工

- [ ] 跑 `scripts\arch-check.ps1`，确认两外壳没有复制内核。
- [ ] 跑 `scripts\gate.ps1`，退出码 0；失败项如实记录。
- [ ] 更新 [变更记录.md](变更记录.md)：改了什么、为什么、判据、证据、未验证项。
- [ ] 源码变更递增版本；文档-only 变更说明理由（R-D-9）。
- [ ] 一个阶段一个 commit；提交信息带阶段号（R-T-9）。
- [ ] 报告只写已验证事实；runner 行为未实测就标“未验证”。

## M0 收尾

- [ ] `gate.ps1 -SelfTest` PASS。
- [ ] 全量 `gate.ps1` 退出 0。
- [ ] `docs/分支归属.md` 六行已填，`main` 在表中。
- [ ] Git 初始化，首个提交包含设计、README、规范、门禁、CI、模板。
- [ ] 变更记录写入 commit hash 与门禁结果。

## M1 接口冻结前

- [ ] `docs/接口冻结.md` 完成：trait、命令、事件、日志字段、错误码、配置键、版本规则。
- [ ] 两个外壳只用同一套 `meito-core` 公共接口。
- [ ] `cargo check` 通过；两个外壳 stub 编译通过。
- [ ] 冻结后任何修改都有变更记录与版本递增。
