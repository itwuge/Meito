## 填写与核对

1. **一行一分支**：每个 worktree 一条分支，只对应一条线；同一线需要新职责时开新 worktree + 新分支 + 新行，不覆盖旧行。
2. **开工前核对**：`git worktree list` 列出实际工作树，`git branch --show-current` 看当前分支；二者都必须能在上表中找到。
3. **提交前核对**：当前分支的"归属线"必须与本次任务一致；不一致就停下，报告指挥，不提交。
4. **合并纪律**：各线分支不得自行合并 `master`（R-T-7）；合并由指挥统一安排后在表中更新状态。
5. **禁止改写历史**：未经指挥安排，不做 rebase / reset / 强制切分支。
6. **状态取值**：进行中 / 待合并 / 已合并 / 已废弃（废弃行保留，不删除）。
