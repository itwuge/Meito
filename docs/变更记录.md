### 设计取舍

1. 中继方案（uptermd、tmate-ssh-server、cloudflared/ngrok、Cloudflare Named Tunnel、Guacamole 网关）全部排除，因为字节会经过用户服务器。
2. P2P 主路径 frp `xtcp`，备路径 Headscale/Tailscale 直连；禁止 `fallbackTo`/`stcp`/DERP/peer relay。
3. 网页版 WebRTC DataChannel + STUN，禁用 TURN；对称 NAT/UDP 被封时 `E_WEB_NO_DIRECT_PATH` 并转本地版。
4. 一套 Rust 内核、两个外壳；网页版不复制状态机/artifact/P2P 策略。
5. M1 独立为“接口冻结”阶段，两外壳在冻结后并行。
