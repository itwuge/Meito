### M1 契约要点

1. CLI：16 个子命令 + 7 个全局参数；退出码 0–12；错误码 23 个，含网页版打不通的 `E_WEB_NO_DIRECT_PATH`（11）与检测到中继的 `E_WEB_RELAY_USED`（11）。
2. 日志：JSONL 固定六字段 `ts/level/session_id/stage/event/error_code`；路径 `logs/session-<id>.jsonl`；stage 枚举与状态机 states 完全一致；脱敏 key 覆盖 token/authorization/private_key/secret/password/session_connect_string/frps_token/tailscale_authkey/oauth_code/turn_credential。
3. workflow：10 个输入；连接包只经 `meito-link` 加密下发，不进 artifact/日志/Job Summary；Job Summary 只含 presence 与过期时间；artifact manifest 用 SHA256 + `checksums.filesSha256/archiveSha256` + `guardPassed` 校验。
4. 状态机：25 个状态、27 个事件、转移表与超时/自动取消判定点（job 360、会话上限 300、无人加入 5 min → `E_NO_JOIN_TIMEOUT`）。
5. BYO TURN：全部契约保持 `reserved`、`enabled=false`、`decision=pending`、`decisionId=D-4`；未填任何默认值。

2. 新增 `connection-package.json`：magic `MEITO1`（6 字节）+ 格式版本 1 + 算法 id 字节 0（`x25519-xchacha20poly1305`）+ 临时公钥 32 + nonce 24 + 密文（含 tag，变长）；线格式 `base64url-no-padding`；密钥对 runner 侧每作业临时生成、不导出、用后清零；服务端 `ciphertext-only`、`parse=false`、`log=false`。
3. 新增 `udp-probe.json`：目标取 `meito.toml [network] udp_probe_target`（`host:port`，无默认值）；请求 `MEITOUDP`（8 字节）+ 8 字节随机 nonce；回执回同一 nonce；3 次 × 1000 ms；`meito-link` UDP 监听 `defaultEnabled=false`，仅自检、不转发会话字节。
4. 新增 `meito-config.schema.json`：`[security] allowed_actors` 字符串数组；缺失配置、缺字段、空列表一律 `deny-all`；workflow 覆盖入口 `flags.allowed_actors`，优先级 `override`。

### 0.3.5 要点

1. KDF：HKDF-SHA256；`ikm` 为 X25519 共享密钥；`salt` 固定空串（RFC 5869 等价于零字节），不采用魔数+格式版本；`info` 绑定 `meito-v1` 与 `connection-package`；输出 32 字节 AEAD 密钥。
