### 设计取舍

1. 中继方案（uptermd、tmate-ssh-server、cloudflared/ngrok、Cloudflare Named Tunnel、Guacamole 网关）全部排除，因为字节会经过用户服务器。
2. P2P 主路径 frp `xtcp`，备路径 Headscale/Tailscale 直连；禁止 `fallbackTo`/`stcp`/DERP/peer relay。
3. 网页版 WebRTC DataChannel + STUN，禁用 TURN；对称 NAT/UDP 被封时 `E_WEB_NO_DIRECT_PATH` 并转本地版。
4. 一套 Rust 内核、两个外壳；网页版不复制状态机/artifact/P2P 策略。
5. M1 独立为“接口冻结”阶段，两外壳在冻结后并行。

### M1 契约要点

1. CLI：16 个子命令 + 7 个全局参数；退出码 0–12；错误码 23 个，含网页版打不通的 `E_WEB_NO_DIRECT_PATH`（11）与检测到中继的 `E_WEB_RELAY_USED`（11）。
2. 日志：JSONL 固定六字段 `ts/level/session_id/stage/event/error_code`；路径 `logs/session-<id>.jsonl`；stage 枚举与状态机 states 完全一致；脱敏 key 覆盖 token/authorization/private_key/secret/password/session_connect_string/frps_token/tailscale_authkey/oauth_code/turn_credential。
3. workflow：10 个输入；连接包只经 `meito-link` 加密下发，不进 artifact/日志/Job Summary；Job Summary 只含 presence 与过期时间；artifact manifest 用 SHA256 + `checksums.filesSha256/archiveSha256` + `guardPassed` 校验。
4. 状态机：25 个状态、27 个事件、转移表与超时/自动取消判定点（job 360、会话上限 300、无人加入 5 min → `E_NO_JOIN_TIMEOUT`）。
5. BYO TURN：全部契约保持 `reserved`、`enabled=false`、`decision=pending`、`decisionId=D-4`；未填任何默认值。

### 门禁配置修正（随 M1）

- `gate.config.json` 的 `note.paramSectionRegex` 由“仅匹配文档首行”改为“在文档块内匹配 `# 参数`”，避免把摘要行在前、章节在后的标准 Rust 文档误判为缺少参数说明；不降低对公共函数文档的要求。
- `arch-check.ps1` 的文件头检查原用 `-SimpleMatch` 匹配 `\/\/!`（字面反斜杠），修正为 `//!`。
- `quality-gate.ps1` 优先从 PATH 解析 cargo，回退 `%USERPROFILE%\.cargo\bin\cargo.exe`；存在 `Cargo.toml` 但找不到 cargo 时退出 127，不再伪造 SKIP。
- `gate.ps1` 的变更集读取增加 `-c core.quotepath=false`，修复非 ASCII 路径被 Git 输出为八进制转义、导致 R-T-4 无法识别 `docs/变更记录.md` 的问题。
